按照 Dash 图文指南操作

用户只需完成手机号登录，并把登录手机号提供给运营人员。主机添加与绑定由运营人员内部完成，用户无需操作。

  2. 2打开 Dash，使用手机号和短信验证码登录。
  3. 3把登录 Dash 的手机号提供给运营人员，等待运营人员完成主机绑定。
  4. 4运营人员通知绑定完成后，进入“对话”选择模型并发送。

04
排查问题

遇到问题先看这里

登录后没有显示主机

用户无需自行添加或绑定主机。请把登录 Dash 使用的手机号提供给运营人员，由运营人员在内部完成主机绑定。

主机显示“连接”或“重新连接”

点击“连接”或“重新连接”，等待主机名称旁出现绿色圆点和“正在使用”。仍失败时保存当前页面截图并联系运营人员。

页面中没有模型

刷新或重启 Dash；仍没有模型时联系管理员确认服务状态和账号权限。

点击生成后任务失败

保存错误提示、控制台信息和操作系统版本，并说明所选模型与操作步骤后联系管理员。

macOS 下载后无法打开软件

请先确认下载的是本页面提供的最新版本，并核对文件名与校验值。重新下载后，将 Siltok Dash 拖入“应用程序”，再从“应用程序”文件夹打开；仍无法打开时截图联系运营人员。

微信里不能下载安装包

请复制本页地址到 Chrome、Edge 或 Safari 打开，再点击下载按钮。
